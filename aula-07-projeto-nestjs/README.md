# 🚀 Aula - Introdução ao NestJS

## 📚 Sobre a aula

Nesta aula foi criado e configurado um projeto utilizando o **NestJS**, um framework para desenvolvimento de aplicações **Node.js** utilizando **TypeScript**.

O objetivo foi conhecer a estrutura inicial de um projeto NestJS, entender seus principais arquivos e executar a aplicação localmente.

---

## 🛠️ Tecnologias utilizadas

* **Node.js**
* **NestJS**
* **TypeScript**
* **NPM**

---

## 📁 Estrutura do projeto

Durante a criação do projeto, foi possível conhecer a estrutura básica do NestJS, incluindo:

* `src/` → contém os arquivos principais da aplicação.
* `app.controller.ts` → responsável pelas rotas/controladores.
* `app.service.ts` → contém a lógica de serviço da aplicação.
* `app.module.ts` → módulo principal que organiza os componentes.
* `main.ts` → arquivo responsável por iniciar a aplicação.
* `package.json` → contém as dependências e os scripts do projeto.
* `tsconfig.json` → configurações do TypeScript.

---

## ⚙️ Configuração do projeto

O projeto foi criado utilizando o NestJS e suas dependências foram instaladas com:

```bash
npm install
```

Após a instalação, a aplicação ficou pronta para ser executada.

---

## ▶️ Executando o projeto

Para iniciar a aplicação em modo de desenvolvimento:

```bash
npm run start:dev
```

O modo `start:dev` permite que a aplicação seja reiniciada automaticamente quando alterações forem realizadas no código.

Também é possível executar normalmente com:

```bash
npm run start
```

---

## 🧪 Testes

O projeto também possui uma estrutura preparada para testes.

Para executar os testes unitários:

```bash
npm run test
```

Para executar os testes end-to-end:

```bash
npm run test:e2e
```

Para verificar a cobertura dos testes:

```bash
npm run test:cov
```
